# TomoPlan - Google Apps Script (GAS) バックエンド設定手順書

TomoPlanは **完全無料（0円）** で Google スプレッドシートをデータベースとして利用できます。
この設定を行うと、URLが `https://.../#/e/evt_xxxx` という短い形式になり、複数人でのリアルタイム同期が可能になります。

---

## 🚀 3分で完了するセットアップ手順

### ステップ 1: Google スプレッドシートを新規作成
1. ブラウザで [Google スプレッドシート](https://sheets.new) を新規作成します。
2. スプレッドシートのタイトルを「**TomoPlan データベース**」などに変更します。

---

### ステップ 2: Apps Script エディタを開く
1. 上部メニューから **「拡張機能」** ＞ **「Apps Script」** をクリックします。
2. プロジェクト名を「**TomoPlan Backend**」などに変更します。

---

### ステップ 3: `Code.gs` のコードを貼り付け
1. エディタに最初から書かれている `function myFunction() {}` をすべて消去します。
2. 本リポジトリの [`gas/Code.gs`](./Code.gs) の内容をすべてコピーして貼り付けます。
3. 上部の **「保存（フロッピーディスクのアイコン）」** または `Ctrl + S` を押して保存します。

---

### ステップ 4: 初期シート自動作成を実行
1. 上部の関数選択ドロップダウンから **`setupSheets`** を選択します。
2. **「実行」** ボタンを押します。
3. 初回実行時は **「承認が必要です」** というダイアログが出ます：
   - 「権限を確認」をクリック
   - 自分の Google アカウントを選択
   - 「詳細」をクリック ＞ 「TomoPlan Backend（安全ではないページ）に移動」をクリック
   - 「許可」をクリック
4. 実行ログに `🎉 TomoPlan のシートセットアップが完了しました！` と表示されたら、スプレッドシートに `Events`, `Candidates`, `Responses` の3つのシートが自動生成されます。

---

### ステップ 5: Web アプリとしてデプロイ
1. 右上の青いボタン **「デプロイ」** ＞ **「新しいデプロイ」** をクリックします。
2. 左側の歯車アイコン「種類の選択」から **「ウェブアプリ」** を選びます。
3. 以下の通り設定します：
   - **説明**: `v1` （任意）
   - **次のユーザーとして実行**: **自分**（`me`）
   - **アクセスできるユーザー**: **全員**（`Anyone`） ※友達がログイン不要でアクセスするため
4. **「デプロイ」** をクリックします。
5. 表示された **「ウェブアプリのURL」** （例: `https://script.google.com/macros/s/AKfycb.../exec`）をコピーします。

---

### ステップ 6: `config.js` に貼り付け
1. TomoPlanのプロジェクト内にある `config.js` を開きます。
2. コピーしたURLを `GAS_API_URL` に貼り付けます：

```javascript
const CONFIG = {
  // ここにコピーしたウェブアプリURLを貼り付け
  GAS_API_URL: 'https://script.google.com/macros/s/AKfycb.../exec'
};
```

これだけで連携完了です！ブラウザで TomoPlan を開くと、右上に「☁️ クラウド連携中」と表示され、短いURL（`#/e/{id}`）で友達に共有できるようになります。

---

## 🔒 セキュリティ＆運用上の特徴
- **完全無料**: Google の無料アカウント枠（1日2万回のURLフェッチ、6分の実行時間等）で動作し、友達同士の利用では上限に達する心配はありません。
- **排他制御（LockService）**: 同時に複数人が回答を送信しても、データが壊れたり競合したりしないよう排他ロックをかけています。
- **フォールバック設計**: `config.js` が空文字のままであっても、アプリはエラーにならず自動的にローカルストレージ＆ハッシュモードで動作します。
